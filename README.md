# 时铸 · TIMINT

**为目标沉淀，为热爱解锁。**
*Accumulate for goals, unlock for love.*

用专注时间解锁现实心愿的番茄钟（Windows 10 / 11）。数据只保存在自己电脑上，不联网上传。

## 📥 怎么安装

1. 打开 **[最新版本下载页](https://github.com/MLLeosf/focus-reward/releases/latest)**
2. 只下载 **`TIMINT-Setup-版本号.exe`**（安装包本体，约 200 MB），其他文件不用管
3. 双击安装。第一次打开如果出现「Windows 已保护你的电脑」，点 **「更多信息」→「仍要运行」**

## 🔄 怎么更新

装好以后不用再来这里：软件会自动检查新版本并弹出提示，点「立即更新」即可；也可以在 **「设置 → 关于与更新」** 里手动更新。学习记录不会丢。
